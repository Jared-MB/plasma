## Install

```bash tab="pnpm"
pnpm add @crm/plasma
```

```bash tab="npm"
npm add @crm/plasma
```

```bash tab="yarn"
yarn add @crm/plasma
```

```bash tab="bun"
bun add @crm/plasma
```

## TypeScript

Is highly recommended to use TypeScript with Plasma. 
Plasma is designed to work with TypeScript and provides type safety for your API routes. 
Without it, you lose many of the benefits of using Plasma.
